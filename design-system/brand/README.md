# Marca — Kerberos

Logo em traço fino com o cérbero de três cabeças. Origem: kit de marca Kerberos (SVG vetorizado;
wordmark em Montserrat Bold, SIL OFL, já convertido em contorno).

| Arquivo | Uso | Tamanho mínimo |
|---|---|---|
| `logo.svg` | Lockup vertical em fundo claro ou no gradiente: login e telas de entrada | 96 px de altura |
| `logo-inverse.svg` | Lockup vertical em fundo escuro | 96 px de altura |
| `logo-mark.svg` | Lockup horizontal com traço reforçado: barras, cabeçalhos, cards | 24 px de altura |
| `app-icon.svg` | Favicon (símbolo; adapta-se ao tema escuro do navegador) | 16 px (os detalhes somem) |

## Regras
- Cores da marca (só no logo, não na interface): navy `#132340` → carmim `#9B1B30`; em fundo escuro, `#C9D3E8` → `#E8586D`.
  A interface continua com os tokens de `design-system/tokens.css`.
- Não recolorir, esticar, girar nem aplicar sombra. Área de respiro: no mínimo a altura da letra "K" em volta.
- O repo guarda só o que o web usa. O kit completo (PNG, iOS, Android e gerador) fica fora dele; para mudar o logo,
  regenere o kit e substitua estes arquivos mantendo os nomes.
